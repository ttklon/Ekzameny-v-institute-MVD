# Ответы на вопросы: варианты

В этой папке лежат ответы на все 149 вопросов. Вариантов ответов будет три, каждый — в своей папке; готовы два.

| Папка | Что внутри | Состояние |
|---|---|---|
| `Вариант 1. Подробные ответы` | подробные ответы со ссылками на нормы, примерами и блоком «Главное для запоминания» | готов |
| `Вариант 2. Сокращённые ответы` | построен как вариант 1, но примерно вдвое короче (около 150 тыс. слов против 314 тыс.; при чтении со скоростью 100 слов в минуту — около 25 часов против 52, из них блоки «Главное для запоминания» — около 3 часов): без примеров, типичных ошибок и вопросов для самопроверки; нормы приводятся дословными цитатами с точными ссылками; сведения из учебной и научной литературы даны без указания автора и издания; в конце каждого ответа — блок «Главное для запоминания», и в тексте ответа оставлено прежде всего то, на что этот блок опирается; каждый акт назван полным названием при первом упоминании; в разделе «Правовая основа» акты перечислены с указанием, что каждый регулирует, а дословные нормы приведены в разделах по существу. Объём получен сокращением проверенной редакции на 36 часов: убраны пояснения, второстепенные пункты и часть подробностей внутри разделов; перечень с вводной строкой либо оставлен целиком, либо убран целиком | готов |
| Вариант 3 | ответы в другом стиле или объёме | будет добавлен |

В папке варианта два вида файлов с одним и тем же текстом:

- `Все ответы 001–149 (один файл).docx` — один документ на все вопросы. В начале стоит содержание: щелчок по строке с нажатой клавишей Ctrl открывает ответ.
- `Ответы на вопросы NNN–NNN.docx` — те же ответы, по десять вопросов в файле.
