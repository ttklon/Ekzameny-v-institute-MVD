# Ответы на вопросы: варианты

В этой папке лежат ответы на все 149 вопросов. Вариантов ответов будет три, каждый — в своей папке; готовы два.

| Папка | Что внутри | Состояние |
|---|---|---|
| `Вариант 1. Подробные ответы` | подробные ответы со ссылками на нормы, примерами и блоком «Главное для запоминания» | готов |
| `Вариант 2. Сокращённые ответы` | построен как вариант 1, но примерно в 1,6 раза короче (около 197 тыс. слов против 314 тыс.; при чтении со скоростью 100 слов в минуту — около 33 часов против 52, из них блоки «Главное для запоминания» — около 3 часов): без примеров, типичных ошибок и вопросов для самопроверки; нормы приводятся дословными цитатами с точными ссылками; сведения из учебной и научной литературы даны без указания автора и издания; в ответах есть раздел или абзац «Правовая основа» с полными названиями актов и дословными нормами; каждый акт, названный в прежней, более длинной редакции варианта 2, назван и в нынешней; разделы о подведомственности дел, группах составов и административной ответственности сохранены; перечни и классификации внутри разделов приведены полностью (сокращены второстепенные разделы и пояснения, а не члены перечней) (в ответах 2, 4–7 он назван по содержанию: «Нормативное закрепление понятий», «Конституционная основа»); в конце каждого ответа — блок «Главное для запоминания» | готов |
| Вариант 3 | ответы в другом стиле или объёме | будет добавлен |

В папке варианта два вида файлов с одним и тем же текстом:

- `Все ответы 001–149 (один файл).docx` — один документ на все вопросы. В начале стоит содержание: щелчок по строке с нажатой клавишей Ctrl открывает ответ.
- `Ответы на вопросы NNN–NNN.docx` — те же ответы, по десять вопросов в файле.
