# Облачный планировщик экзаменов

Приложение для Windows 11, которое превращает файл с вопросами и ответами
в понятный план подготовки: сколько читать каждый день, что уже прочитано,
сколько осталось и когда всё закончится.

Готовые ответы уже внутри: семь дисциплин, 627 вопросов с ответами. По
административной деятельности ответов два — подробный (316 тыс. слов) на
первое чтение и краткий (148 тыс.) на повторения. Добавлять ничего не нужно,
свои файлы тоже читаются.

## Как это работает

В программе три экрана и одно число, которое решает всё: **сколько часов в день
вы готовы читать**. Больше ничего настраивать не нужно.

- **Сегодня** — что читать сегодня, что уже отмечено и кнопка «взять вперёд».
- **Дисциплины** — список предметов; внутри каждой: дата экзамена, часы в день,
  список вопросов. Всё редкое (скорость, число прогонов, выходные) — под
  одной кнопкой «Детали».
- **Настройки** — скорость чтения, оформление, напоминания, данные.

Настраивать заранее ничего не нужно — три шага:

1. **Выберите дисциплину** — в комплекте семь предметов, в каждом весь перечень
   вопросов к экзамену с ответами:

   | Дисциплина | Вопросов | Объём |
   | --- | --- | --- |
   | Административная деятельность полиции | 149 | 316 тыс. слов + краткий вариант (148 тыс.) |
   | Уголовное право | 117 | 160 тыс. слов |
   | Уголовно-процессуальное право | 108 | 83 тыс. слов |
   | Тактико-специальная подготовка | 87 | 54 тыс. слов |
   | Трудовое право | 70 | 57 тыс. слов |
   | Гражданское процессуальное право | 52 | 40 тыс. слов |
   | Криминалистика | 44 | 49 тыс. слов |

   По административной деятельности ответы в двух вариантах: первый раз
   открывается подробный, при повторном чтении — краткий. Переключается
   в «Деталях» дисциплины («Какой ответ читать»), и время считается
   по тому варианту, который вы действительно читаете.

2. **Поставьте дату экзамена** — программа предложит дату через месяц,
   поменяйте на свою. От неё считается вся нагрузка.
3. **Читайте по списку** — каждый день на экране «Сегодня» список вопросов
   с отметками. Отметили — план пересчитался.

Свои файлы добавляются кнопкой «Добавить свой файл» или перетаскиванием:
TXT, DOCX, PDF, ODT, RTF, HTML.

## Что где менять

Главное — одно число. Оно на странице дисциплины: **«Сколько часов в день вы
готовы читать»**. Программа делит весь объём на дни до экзамена ровно по этой
цифре, поэтому в понедельник и в пятницу выходит примерно одинаково.

Если прочитали больше нормы — например, сегодня были силы на четыре вопроса
вместо двух, — следующие дни автоматически станут легче: норма считается от
того, что осталось. Кнопка **«Взять вперёд»** на экране «Сегодня» открывает
первый вопрос из ближайших дней — отметить прочитанное можно за любой день.

Ошиблись с отметкой? Нажмите на неё ещё раз или на «снять» в списке «Уже
отмечено»; после «Отметить всё» в плашке есть **«Отменить»**, а «Снять всё»
возвращает целый день одним нажатием — и тоже с отменой.

**«Настройки» — для всего приложения:**

| Что | Зачем |
| --- | --- |
| Скорость чтения (ползунок) | От неё зависит время каждого ответа и норма дня. Сразу видно, сколько займёт ваш средний ответ. |
| Звуки, небо, анимации | Оформление. |
| Напоминания, трей, автозапуск | Чтобы не забывать про занятия. |
| Тонкая настройка (свёрнуто) | Коэффициенты и интервалы — для тех, кто хочет всё под контролем. Обычно не нужно. |

**«Детали» внутри дисциплины — только для неё:**

| Что | Зачем |
| --- | --- |
| Сколько раз прочитать | Например, «3 полных прочтения». |
| Скорость чтения | Своя скорость, если предмет читается легче или тяжелее остальных. |
| Нагрузка по дням недели | «отдых / обычно / ×1,5 / ×2 / ×3 / ×4» и точные минуты: если в субботу можете 4 часа, а в будни час — так и впишите. |
| Какой ответ читать | Если у дисциплины есть краткий вариант. |

Если не трогать настройки вообще, всё работает: программа делит объём поровну
на дни до экзамена, считает по 150 слов в минуту и ставит 3 прочтения.

## Что программа понимает в файлах

Разбор идёт по нескольким правилам, и в окне импорта видно, какое сработало:

| Формат файла | Что распознаётся |
| --- | --- |
| `# Вопрос 12. Текст` / `## Задача 3` | заголовки вопросов |
| `Вопрос 12. Текст` без решётки | заголовки вопросов |
| `1. Текст` … `149. Текст` | нумерованный перечень |
| `1. Вопрос` + `Ответ: …` | вопрос и ответ по маркеру |
| файл на один вопрос | заголовок — вопрос, всё остальное — ответ |
| строки с «?» | вопросы без нумерации |
| вопрос и ответ подряд | без пустых строк между ними: заголовок, сразу ответ, сразу следующий номер |
| заголовок в две-три строки | продолжение заголовка не путается с ответом |

Если ответов в файле нет (только перечень вопросов), объём оценивается по
средней длине — об этом честно сказано в предупреждении, а оценку можно
поменять в настройках дисциплины.

Кодировка определяется сама: UTF-8, UTF-8 с BOM, UTF-16, Windows-1251.
PDF читается через pdf.js; если PDF — скан без текстового слоя, программа
скажет об этом и предложит сохранить файл в DOCX или TXT.

## Как считается план

- Время чтения = объём (слова или знаки) ÷ ваша скорость чтения × поправка
  на сложность текста. Скорость настраивается: по умолчанию 150 слов/мин.
- Повторные прогоны дешевле первого: коэффициент 1,5 (настраивается).
- Интервалы между прогонами расширяются, первый — около 15 % оставшегося
  времени. Это соответствует данным о распределённом повторении: серия
  повторений с растущими промежутками запоминается лучше, чем чтение подряд.
- Если задано общее ограничение по времени в день, нагрузка делится между
  дисциплинами так, чтобы каждая двигалась каждый день, а не по очереди.
- Норма дня — ровная полоса: остаток делится на оставшиеся дни, вопрос ставится
  в день, только если он в эту полосу влезает. Поэтому нагрузка распределяется
  ровно даже при маленьком объёме — и ничего не сваливается в последний день.
- Прочитанное сверх нормы уменьшает остаток, а значит и все следующие дни:
  так работает чтение вперёд.
- Один вопрос не читается дважды за день, и повтор никогда не встаёт раньше
  предыдущего прочтения — даже если план пришлось сдвинуть.
- Нагрузку можно разложить по дням недели: «отдых», «обычно», «×1,5», «×2»,
  «×3», «×4» — или вписать точные минуты для каждого дня. Вес дня меняет и
  ёмкость, и куда ставятся новые вопросы, поэтому воскресенье действительно
  получается тяжелее остальных дней — даже когда срок тесный.
- Программа не навязывает свой потолок: вы говорите, сколько готовы читать
  в обычный день (хоть два часа, хоть восемь), и план считается от этой цифры.
  Предупреждение о перегрузке появляется только относительно вашей же цифры.
- При перегрузке (например, 150 вопросов за три дня) программа предупредит
  и покажет, сколько минут в день реально нужно.

## Обновления

Приложение раз в минуту спрашивает у GitHub, не вышла ли новая сборка. Само оно
ничего не скачивает: появляется плашка «Вышло обновление» с кнопками
**Обновить** и **Позже**. После нажатия «Обновить» файл скачивается, сверяется
по размеру с тем, что сообщил GitHub, и запускается установщик — приложение
закрывается, работа продолжается в новой версии.

- Проверить вручную: «Настройки» → «Версия и сборка» → «Проверить обновление».
- Библиотека, отметки и тексты лежат в отдельной папке (`AppData`) — обновление
  их не затрагивает.
- Если GitHub недоступен, приложение работает как обычно, а пауза между
  проверками увеличивается, чтобы не упираться в лимит запросов.

## Что внутри

```
app/
├── main.js                  главный процесс: окно, меню, файловые операции
├── preload.js               узкий мост между интерфейсом и системой
├── src/
│   ├── core/                общая логика (работает и в тестах)
│   │   ├── text.js          подсчёт слов, знаков, сложность, время чтения
│   │   ├── parser.js        разбор файлов «вопрос — ответ»
│   │   └── planner.js       распределение по дням, повторения, прогноз
│   └── main/                чтение файлов: кодировки, DOCX/ODT/RTF, PDF
├── renderer/                интерфейс: HTML, CSS, небо, звук, экраны
└── test/                    проверки ядра и интерфейса (npm test)
```

Данные лежат в `%APPDATA%\Облачный планировщик экзаменов`: `library.json`
(библиотека, отметки, настройки) и папка `texts/` с копиями добавленных
файлов. Запись атомарная, рядом всегда есть `.bak` — при повреждении
основного файла библиотека восстанавливается из копии.

## Проверки

```bash
cd app
npm install
npm test
```

В проверках пять наборов (ядро, главный процесс, договор, напоминания,
интерфейс) — больше сотни отдельных проверок:

| Набор | Что проверяет |
| --- | --- |
| `core.test.js` | подсчёт слов и знаков, разбор реальных файлов, порядок вопросов и личный дневной объём, инварианты плана (ничего не потеряно, ничего не запланировано после экзамена), даты, кодировки, DOCX |
| `main.test.js` | сохранение библиотеки, восстановление из резервной копии, копии текстов, выгрузка |
| `contract.test.js` | договор интерфейс ⇄ мост ⇄ главный процесс, CSP, порядок скриптов, локальные ресурсы |
| `remind.test.js` | напоминания, трей, запуск вместе с Windows |
| `dom.test.js` | три экрана в jsdom: импорт, окно вопроса, отметки и их отмена, чтение вперёд, свой объём дня |
