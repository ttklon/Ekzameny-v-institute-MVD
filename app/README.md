# ☁️ Облачный планировщик экзаменов

Красивое приложение на **Electron** (Windows 11) для подготовки к экзаменам по большим
файлам с вопросами и ответами. Само определяет вопросы и ответы, считает слова/знаки/время,
строит равномерный план подготовки к конкретной дате, пересчитывает нагрузку при отставании
и позволяет отмечать конкретные прочитанные вопросы.

## Возможности

- **Универсальный приёмник файлов** — перетащите `.txt`/`.md` с вопросами. Распознаёт форматы:
  - `1. Вопрос` … `2. Вопрос` (нумерованный список)
  - `Вопрос 1` … `Ответ:` … (явные маркеры)
  - строки-вопросы (заканчивающиеся на `?`)
  - авто-декодирование UTF‑8 / Windows‑1251 / UTF‑16
  - отбрасывает мусор от PDF (одиночные номера страниц и т.п.)
- **Статистика** по каждому вопросу: слова, знаки, время чтения (по вашей скорости).
- **Параметры на дисциплину**: дата начала, дата экзамена, число прогонов
  («прочитать файл N раз»), режим нагрузки:
  - *по N вопросов в день*,
  - *по минутам в день*,
  - *в общем бюджете* (готовиться ко всем понемногу каждый день),
  - выходные дни, коэффициент скорости повторения.
- **Авто-пересчёт**: помечаете «прочитал 8 из 10, вот эти номера» — план
  перераспределяет оставшееся по оставшимся дням и показывает, сколько теперь нужно в день.
- **Сегодня / любой день**: чек‑лист вопросов с номерами, отметка конкретных прочитанных.
- **Статистика**: кольца готовности, распределение минут по дням, объёмы.
- **Советы**: что говорит когнитивная наука про подготовку (с источниками).
- **Интерфейс**: живая тема «небо и облака», плавные анимации, мягкие звуки, glassmorphism.

## Запуск и сборка (Windows 11)

```bash
cd app
npm install            # поставит Electron и electron-builder
npm start             # запустить в режиме разработки
npm run dist:win      # собрать установщик NSIS для Windows (ОблачныйПланировщикЭкзаменов-*-setup.exe)
```

> Для `npm run dist:win` нужен Windows (или среда с возможностью сборки Windows-бинаря).
> На Linux/macOS команда `npm run dist` соберёт пакет для вашей ОС.

## Структура

```
app/
  main.js              главный процесс: окно, чтение/декодирование файлов, хранение
  preload.js           безопасный мост к API
  src/core/
    textstats.js       подсчёт слов/знаков/времени
    parser.js          универсальный парсер вопрос-ответ
    planner.js         движок планирования и пересчёта
  renderer/
    index.html
    css/style.css      тема «небо и облака»
    js/app.js          контроллер интерфейса
    js/audio.js        синтезированные звуки (Web Audio)
    js/clouds.js       анимированное небо (canvas)
  test/
    core.test.js       проверка ядра на реальном файле репозитория
    dom.test.js        headless-прокурка интерфейса (jsdom)
```

## Проверка логики без GUI

```bash
npm test              # node test/core.test.js
```

## Как готовиться эффективно (заложено в расчёт)

- Распределяйте материал по дням, а не «зубрите» за ночь (spaced practice).
- Повторяйте материал 3–5 раз с разрывом (параметр «прогонов»).
- Готовьтесь ко всем дисциплинам понемногу каждый день (режим «в общем бюджете»).
- Отмечайте конкретные прочитанные вопросы — план сам пересчитает остаток.

Источники и подробности — во вкладке «Советы» в приложении.
