# Облачный планировщик экзаменов

Приложение для Windows 11, которое превращает файл с вопросами и ответами
в понятный план подготовки: сколько читать каждый день, что уже прочитано,
сколько осталось и когда всё закончится.

Встроенных файлов с ответами нет — программа работает с вашими файлами.

## Скачать

Готовая сборка лежит в разделе [Releases](../../releases/tag/app-latest):

- **CloudExamPlanner-1.0.0-x64.exe** — установщик, ярлык в «Пуск» и на рабочем столе;
- **CloudExamPlanner-1.0.0-portable.exe** — портативная версия без установки.

Windows может показать предупреждение SmartScreen («Неизвестный издатель»):
подпись кода не покупалась. Нажмите «Подробнее» → «Выполнить в любом случае».

## Как это работает

1. **Добавьте файл** — кнопкой «Добавить файл», перетаскиванием в окно или
   целой папкой. Поддерживаются TXT, DOCX, PDF, ODT, RTF, HTML.
2. **Проверьте, что нашлось** — программа покажет число вопросов, объём
   каждого ответа в словах и знаках, время чтения и предупреждения.
3. **Задайте дату экзамена и число прогонов** — например, «3 полных
   прочтения до 24 декабря».
4. **Читайте по плану** — каждый день на экране «Сегодня» список вопросов
   с отметками. Отметили — план пересчитался.
5. **Смотрите прогресс** на экранах «Обзор», «Календарь» и «Статистика».

## Что программа понимает в файлах

Разбор идёт по нескольким правилам, и в окне импорта видно, какое сработало:

| Формат файла | Что распознаётся |
| --- | --- |
| `# Вопрос 12. Текст` / `## Задача 3` | заголовки вопросов |
| `Вопрос 12. Текст` без решётки | заголовки вопросов |
| `1. Текст` … `149. Текст` | нумерованный перечень |
| `1. Вопрос` + `Ответ: …` | вопрос и ответ по маркеру |
| файл на один вопрос | весь файл — один вопрос с ответом |
| строки с «?» | вопросы без нумерации |

Если ответов в файле нет (только перечень вопросов), объём оценивается по
средней длине — об этом честно сказано в предупреждении, а оценку можно
поменять в настройках дисциплины.

Кодировка определяется сама: UTF-8, UTF-8 с BOM, UTF-16, Windows-1251.
PDF читается через pdf.js; если PDF — скан без текстового слоя, программа
скажет об этом и предложит сохранить файл в DOCX или TXT.

## Как считается план

- Время чтения = объём (слова или знаки) ÷ ваша скорость чтения × поправка
  на сложность текста. Скорость настраивается: по умолчанию 150 слов/мин.
- Повторные прогоны дешевле первого: коэффициент 1,5 (настраивается).
- Интервалы между прогонами расширяются, первый — около 15 % оставшегося
  времени. Это соответствует данным о распределённом повторении: серия
  повторений с растущими промежутками запоминается лучше, чем чтение подряд.
- Если задано общее ограничение по времени в день, нагрузка делится между
  дисциплинами так, чтобы каждая двигалась каждый день, а не по очереди.
- При перегрузке (например, 150 вопросов за три дня) программа предупредит
  и покажет, сколько минут в день реально нужно.

## Что внутри

```
app/
├── main.js                  главный процесс: окно, меню, файловые операции
├── preload.js               узкий мост между интерфейсом и системой
├── src/
│   ├── core/                общая логика (работает и в тестах)
│   │   ├── text.js          подсчёт слов, знаков, сложность, время чтения
│   │   ├── parser.js        разбор файлов «вопрос — ответ»
│   │   └── planner.js       распределение по дням, повторения, прогноз
│   └── main/                чтение файлов: кодировки, DOCX/ODT/RTF, PDF
├── renderer/                интерфейс: HTML, CSS, небо, звук, экраны
└── test/                    проверки ядра и интерфейса (npm test)
```

Данные лежат в `%APPDATA%\Облачный планировщик экзаменов`: `library.json`
(библиотека, отметки, настройки) и папка `texts/` с копиями добавленных
файлов. Запись атомарная, рядом всегда есть `.bak` — при повреждении
основного файла библиотека восстанавливается из копии.

## Проверки

```bash
cd app
npm install
npm test
```

39 проверок ядра и 29 проверок интерфейса: разбор реальных файлов,
инварианты плана (ничего не потеряно, ничего не запланировано после
экзамена), отметки и пересчёт, все экраны в jsdom.

## Сборка

```bash
cd app
npm install
npm run dist:win
```

GitHub Actions собирает установщик и портативную версию на `windows-latest`
и выкладывает их в релиз `app-latest` (см. `.github/workflows/build-windows.yml`).
