## Структура папки дисциплины

```
<Дисциплина>/
├── 1. Примерный перечень вопросов/   — перечень вопросов в исходном виде
├── 2. Источники/
│   ├── 0. Загружено пользователем/   — сюда можно складывать свои материалы без сортировки
│   ├── 1. Нормативные правовые акты/
│   ├── 2. Судебная практика/
│   ├── 3. Учебная литература/
│   ├── 4. Научные материалы (с 2023 года)/
│   ├── 5. Эмпирические материалы (с 2023 года)/
│   └── Реестр источников.md          — учёт каждого файла: реквизиты, редакция, откуда и когда получен
└── 3. Ответы на вопросы/             — итоговый документ Word с ответами на все вопросы
```

Подробная разбивка папки «Источники» сделана для административной деятельности полиции и для криминалистики: по этим двум дисциплинам базы источников собраны. У остальных дисциплин создан базовый каркас; он детализируется, когда начинается сбор источников по дисциплине. Перечни вопросов сохранены в том виде, в каком переданы (файлы не правились).

Имена файлов длинные: путь к файлу внутри репозитория доходит до 267 знаков. В Windows перед клонированием нужно разрешить длинные пути: `git config --global core.longpaths true`. При распаковке ZIP-архива репозитория распаковывайте его в папку с коротким путём (например, `C:\\r`).

## Правила работы с источниками

1. В ответах используются только те источники, файлы которых лежат в репозитории. Источник, которого нет в папке, не цитируется.
2. Источники сохраняются в исходном виде (официальная публикация, PDF издания и т. п.) и в полном объёме.
3. По каждому нормативному акту проверяется действующая редакция и то, что акт не утратил силу. Дата проверки заносится в реестр.
4. Научные и эмпирические материалы — не старше 2023 года, предпочтительно 2025–2026 годов.
5. Каждый источник вносится в `Реестр источников.md` с адресом, откуда он получен, и датой получения.

## Требования к ответам

- Ответ на каждый вопрос — подробный, исчерпывающий, юридически точный, в академическом стиле, без двусмысленных формулировок.
- Каждое положение ответа подкреплено ссылкой на конкретный источник из папки (статья, пункт, страница).
- К каждому вопросу — вероятные дополнительные вопросы преподавателя с ответами.
- Итог по дисциплине — один документ Word в папке «3. Ответы на вопросы».
