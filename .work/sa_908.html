Приказ МВД России от 27.11.2023 N 908 Об утверждении Наставления по организации деятельности центров временного содержания для несовершеннолетних правонарушителей органов внутренних дел (Зарегистрировано в Минюсте России 07.02.2024 N 77156)


Приказ
Наставление по организации деятельности центров временного содержания для несовершеннолетних правонарушителей органов внутренних дел
I. Общие положения
II. Прием и регистрация несовершеннолетних
III. Содержание несовершеннолетних
IV. Организация индивидуальной профилактической работы
V. Организация передачи несовершеннолетних, содержащихся в ЦВСНП, родителям или иным законным представителям и в специальные учебно-воспитательные учреждения закрытого типа
Приложение N 1. Журнал наряда ЦВСНП (рекомендуемый образец)
Рапорт
Приложение N 2. Акт личного осмотра несовершеннолетнего и его вещей или получаемых им почтовых отправлений и передач (рекомендуемый образец)
Приложение N 3. Журнал учета несовершеннолетних, доставленных в ЦВСНП (рекомендуемый образец)
Приложение N 4. Учетно-статистическая карточка (рекомендуемый образец)
Приложение N 5. Учетно-статистическое дело несовершеннолетнего, доставленного в ЦВСНП (рекомендуемый образец)
Уточненные данные
Приложение N 6. Анкета несовершеннолетнего, доставленного в ЦВСНП (рекомендуемый образец)
Приложение N 7. Акт о передаче несовершеннолетнего (рекомендуемый образец)
Приложение N 8. Заключение о результатах работы психолога с несовершеннолетним (рекомендуемый образец)
Приложение N 9. Рабочий журнал психолога ЦВСНП (рекомендуемый образец)
1. Учет лиц, прошедших тестирование
2. Учет мероприятий в индивидуальной форме
3. Учет мероприятий в групповой форме
4. Учет консультаций с несовершеннолетними, их родителями или иными законными представителями
Приложение N 10. Перечень транзитных ЦВСНП, предназначенных для приема, содержания и перевозки несовершеннолетних по территории Российской Федерации и государств - участников СНГ
