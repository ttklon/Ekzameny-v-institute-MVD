Приказ МВД России от 29.03.2019 N 205 (ред. от 27.10.2025) О несении службы участковым уполномоченным полиции на обслуживаемом административном участке и организации этой деятельности (вместе с Инструкцией по исполнению участковым уполномоченным полиции служебных обязанностей на обслуживаемом административном участке, Наставлением по организации службы участковых уполномоченных полиции) (Зарегистрировано в Минюсте России 03.07.2019 N 55115)


Приказ
Приложение N 1. Инструкция по исполнению участковым уполномоченным полиции служебных обязанностей на обслуживаемом административном участке
I. Общие положения
II. Несение службы участковым уполномоченным полиции на обслуживаемом административном участке
III. Профилактический обход административного участка
IV. Рассмотрение обращений и прием граждан
V. Проведение индивидуальной профилактической работы
VI. Участие участкового уполномоченного полиции в иных мероприятиях по профилактике правонарушений
VII. Отчет перед населением
Приложение N 1. График несения службы участковых уполномоченных полиции (Рекомендуемый образец)
Приложение N 2. Форма ежедневного отчета участковых уполномоченных полиции по несению службы на административном участке (Рекомендуемый образец). - Утратило силу
Приложение N 3. Материально-техническое обеспечение участковых пунктов полиции
Вывеска участкового пункта полиции (Рекомендуемый образец 1)
Информационное табло участкового пункта полиции (Рекомендуемый образец 2)
Приложение N 4. Визитная карточка участкового уполномоченного полиции (Рекомендуемый образец). - Утратило силу
Приложение N 5. График отчетов перед населением участковых уполномоченных полиции о проделанной работе за 20__ год (Рекомендуемый образец)
Приложение N 6. Объявление о предстоящем отчете перед населением участковых уполномоченных полиции о проделанной работе (Рекомендуемый образец)
Приложение N 7. Протокол проведения собрания по вопросу отчета участкового уполномоченного полиции перед жителями административного участка (Рекомендуемый образец)
Приложение N 2. Наставление по организации службы участковых уполномоченных полиции
I. Общие положения
II. Компетенция подразделений, выполняющих функции по организации службы участковых уполномоченных полиции территориальных органов МВД России на региональном уровне
III. Обязанности должностных лиц территориальных органов МВД России на районном уровне по организации службы участковых уполномоченных полиции
IV. Обеспечение контроля за деятельностью участковых уполномоченных полиции
Приложение N 1. Сведения об обстановке на обслуживаемой территории и результатах служебной деятельности участковых уполномоченных полиции территориального органа МВД России на районном уровне
Приложение N 2. Журнал учета учетно-профилактических дел на лиц, освобожденных из мест лишения свободы и имеющих непогашенную или неснятую судимость за совершение тяжкого или особо тяжкого преступления; преступления при рецидиве преступлений; двух и более преступлений, предусмотренных частью первой статьи 228, статьей 228.3, частью первой статьи 231, частью первой статьи 234.1 УК; умышленного преступления в отношении несовершеннолетнего (Рекомендуемый образец)
